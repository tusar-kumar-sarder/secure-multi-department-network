
# Secure Multi-Department Office Network

## Project Overview
A Cisco Packet Tracer lab designed to demonstrate a secure, multi-department office network with VLAN segmentation, inter-VLAN routing, network services, and access control.

## Objectives
- Separate departments using VLANs.
- Enable inter-VLAN communication.
- Configure DHCP and OSPF.
- Implement NAT/PAT and ACLs.
- Improve network security using SSH and switch security features.
- Verify connectivity and troubleshoot network issues.

## Technologies
- Cisco Packet Tracer
- VLANs and Trunking
- Inter-VLAN Routing
- OSPF
- DHCP
- NAT/PAT
- ACLs
- SSH
- Port Security
- PortFast and BPDU Guard
